## Publicar no GitHub Pages

1. Crie um repositório novo
2. Faça upload de todos os arquivos desta pasta (incluindo a pasta `assets/`)
3. Settings → Pages → branch `main` + `/ (root)` → Save
4. Aguarde 1–2 minutos
