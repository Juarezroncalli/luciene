# Site Luciene Lessa — Psicologia & Consultoria

Site one-page institucional.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub
2. Faça upload de **todos** os arquivos desta pasta (mantendo a estrutura)
3. Em **Settings → Pages**, escolha branch `main` e pasta `/ (root)`
4. Em 1–2 minutos seu site está no ar em https://seuusuario.github.io/nome-do-repo/

## Estrutura

- `index.html` — entrada principal
- `styles.css` — estilos
- `app.jsx` — aplicação React (transpilada no navegador)
- `tweaks-panel.jsx` — painel de ajustes
- `image-slot.js` — componente de placeholders de imagem
- `assets/` — logo e fotografias
